# 暗色极简作品集主页设计

日期: 2026-08-03

## 目标

将个人博客首页改造成暗色极简风格的作品集/简历页。

## 风格

- 暗色背景 + 香槟金强调色
- 全站字体使用微软雅黑(标题加粗)
- 克制的极简排版,签名元素为 Hero 区竖排小字

## 色彩令牌

| 用途                     | 色值                   |
| ------------------------ | ---------------------- |
| 遮罩背景(压暗 Bing 壁纸) | rgba(10, 10, 15, 0.85) |
| 卡片表面                 | #14141c                |
| 主文字                   | #f2f2f5                |
| 次要文字                 | #8b8b9b                |
| 强调色                   | #d9b26a                |

## 页面结构

- **导航栏**：固定顶部,半透明暗底,三项链接(主页/关于/作品)锚点滚动,hover 金色
- **Hero 首屏**：全屏居中,超大加粗名字 + 一句话简介 + 两个按钮(查看作品 / 关于我)；名字左侧竖排小字"作品集 · 二〇二六"(writing-mode: vertical-rl)
- **关于我**：标题 + 头像占位 + 一段自我介绍文字
- **作品集**：2×2 卡片网格；每卡 = 渐变缩略图占位 + 标题 + 简介 + 技术标签 + 链接箭头；hover 时金色描边浮现
- **底部**：版权行 © 2026 食我压路

## 范围

- 动效(gsap 加载动画、滚动渐显)由用户自行实现,本设计不含动效
- 作品内容为占位符示例
- 不包含技能栈、联系方式独立区块
